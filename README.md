# Presentation of this project

This project is my first real attempt at making a Juce VST, I wanted to start simple so here it is !

# Implemented

- Core of the plug-in DSP treatment (applying hyperbolic tangent function to each sample of the buffer (tanh)
- Pre-gain (drive) UI linking to the DSP
- Oversampling (because there's spectral aliasing observed for high frequencies)
- APVTS State saving (to save the knobs position when the project is re-opened)
- Output gain slider to adjust the output volume
